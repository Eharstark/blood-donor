# 🩸 LifeLink – Blood Donor Network

LifeLink is a full-stack blood donor management platform that connects blood donors with hospitals during emergencies. The system enables donor registration, hospital authentication, real-time donor search, and emergency blood request management.

## 🚀 Features

### 👤 Donor Module
- Donor Registration
- Blood Group Management
- Availability Status Tracking
- Donor Dashboard

### 🏥 Hospital Module
- Secure Hospital Login
- Search Donors by Blood Group and City
- View Donor Contact Information
- Emergency Blood Request System (In Progress)

### 🔍 Search System
- Real-time donor search
- Blood group filtering
- City-based filtering
- Eligible donor matching
